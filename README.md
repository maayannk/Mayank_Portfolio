# Mayank Verma - Portfolio

A modern, professional portfolio website built with cutting-edge web technologies featuring stunning 3D animations and smooth interactions.

## 🚀 Features

- **3D Interactive Hero Section**: Powered by Three.js with animated star field and floating geometry
- **GSAP Animations**: Smooth scroll-triggered animations throughout the site
- **Glassmorphism Design**: Modern glass-effect UI components
- **Responsive Layout**: Fully responsive design that works on all devices
- **Professional Components**: Custom-built project cards, experience timeline, and skill badges
- **Performance Optimized**: Built with Vite for lightning-fast load times

## 🛠️ Tech Stack

### Frontend
- **React 18** - Modern UI library
- **TypeScript** - Type-safe development
- **Vite** - Next-generation build tool
- **TailwindCSS** - Utility-first CSS framework

### Animations & 3D
- **GSAP** - Professional-grade animation library
- **Three.js** - 3D graphics library
- **@react-three/fiber** - React renderer for Three.js
- **@react-three/drei** - Useful helpers for react-three-fiber
- **Framer Motion** - Production-ready motion library

### UI Components
- **Lucide React** - Beautiful & consistent icons

## 🎨 Design Features

- **Dark Theme** with emerald and cyan accent colors
- **Gradient Text** effects for headings
- **Custom Scrollbar** with emerald theme
- **Hover Animations** on interactive elements
- **Smooth Scroll** behavior
- **Glass Morphism** effects on cards
- **Floating Animations** for 3D elements
- **Pulse Glow** effects

## 📦 Installation

```bash
npm install
```

## 🏃 Development

```bash
npm run dev
```

Visit `http://localhost:5173` (or the port shown in terminal)

## 🔨 Build

```bash
npm run build
```

## 📱 Sections

1. **Hero Section** - 3D animated background with profile and introduction
2. **About Me** - Professional summary
3. **Experience** - Timeline of work experience
4. **Projects** - Featured projects with descriptions and tech stacks
5. **Skills** - Interactive skill badges

- **Primary**: Emerald-500 to Cyan-400 gradient

## 📝 Customization

To customize the portfolio for your own use:

1. Update personal information in `App.tsx`
2. Replace `/me.gif` with your own profile image
3. Modify the `projects` array with your projects
4. Update the `experiences` array with your work history
5. Customize the `skills` array with your tech stack
6. Update social media links

## 🌟 Animation Details

### GSAP Animations
- Hero fade-in and slide-up
- Skill badges with stagger effect and back ease

### Framer Motion
- Spring animations for profile image
- Hover and tap effects on buttons
- Sequential text animations
- Smooth page transitions

### Three.js
- Particle system for stars
- Rotating wireframe geometry
- Ambient and point lighting
- Orbital controls for interaction
